## 复跑

```powershell
.\.venv\Scripts\python.exe scripts/qa/run-baseline.py
```

要求 Node 与 `.nvmrc` 一致、Python 3.12。脚本优先选择项目内 `.runtime-deps` 的 Node，运行时使用独立库，日志输出到 `.tmp/qa-baseline/时间戳/`。没有安装依赖时先按新人上手安装。仅采集新规则观察可用 `--only probes,quality,documents`。

**观察脚本返回 0 只说明采集成功。**新需求是否符合看输出 `meets_new_expectation`，不能把“脚本执行成功”计为验收通过。既有自动回归验证当前基线，不代表 10 月 12 日新需求已实现。

10-13规则场景复跑：`.venv\Scripts\python.exe scripts/qa/daily-rule-checks.py`。固定合成日期、独立库，结果放.tmp/testing-2026-10-13；`--only COURSE`仅定位且另存selected-results.json。查看status及counts，不能把诊断命令退出0当作全部通过。runner观察输出现在位于自身时间戳目录，不覆盖历史10-12结果。
